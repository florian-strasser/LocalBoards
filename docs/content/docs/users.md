# Users

Admin Users are able to navigate to the users page and have a list of all registered users. You can create, update or delete an existing user from here. You can also change the role of an user to admin. 

## First Admin

To set the first user as an admin you will need to access your database directly, afer signing up for an account. Navigate to the users table and change the role of the desired user to "admin".
