# Comments

Comments in LokalBoards allow users to discuss specific tasks, provide updates, or ask questions directly on cards. This feature enhances collaboration by enabling real-time communication among team members.

## Adding a Comment

To add a comment to a card:
1. Open the card by clicking on it.
2. Scroll to the comments section at the bottom of the card.
3. Type your comment in the text box.
4. Click "Post" to add the comment.

## Real-Time Updates

Comments are updated in real-time. This means that when one user posts a comment, all other users viewing the same card will see the changes instantly. This feature ensures that everyone stays on the same page and can respond promptly to updates or questions.

## Tips for Using Comments

- Use comments to provide context or additional information about a task.
- Ask questions or clarify doubts directly within the card's comment section.
- Keep comments concise and relevant to the task at hand.
